# vite-lowering

Build-time route lowering with `@chttp/unplugin`, plain JS dist, no scriptc. The plugin statically reads `src/routes.chttp.ts` and emits a specialized dispatch module, so matching requests skip the runtime trie walk. Vite bundles everything (chttp included) into a single ESM `dist/main.js` you run with node.

## Run it

```sh
pnpm install
pnpm build
node dist/main.js        # :3000 (or pass a port: node dist/main.js 4000)
```

Routes: `GET /json`, `GET /user/:id`, `GET /mwd` (middleware header `x-mw: 1`), `GET /dyn` (bailed to runtime).

`pnpm start:runtime` runs the same routes without the generated dispatch for comparison.

## The .chttp/ directory

`src/.chttp/routes.gen.ts` is generated by the plugin at build start. Never hand-edit it: change your routes module and rebuild. The `.gitignore` keeps it out of version control.

## Compiling to a native binary

This template stops at the JS dist. To take the same app to a native ELF through `scriptc build`, see [examples/vite-elf](../vite-elf) and the scriptc section in [PLUGIN.md](../../packages/unplugin/PLUGIN.md).
