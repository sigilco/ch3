# elf-roundtrip

A round-trip between a native ELF server and a typed client emitted by `@chttp/unplugin`. The same routes module is the input to both:

- `scriptc build src/server.ts -o server` lowers `src/routes.chttp.ts` into a static ELF.
- `node scripts/emit-client.mjs` runs `@chttp/unplugin` over the same routes module and writes `src/.chttp/routes.client.ts`, which exports `createClient({ baseUrl })`.
- `verify:elf` starts the ELF and drives it with the typed client.
- `verify:node` starts `src/server.ts` under `node --experimental-strip-types` and drives it with the same client, proving the unplugin's emit is consumable as plain TS.

The scriptc build and the unplugin emit are independent: scriptc does not see `.chttp/routes.client.ts`, and the unplugin does not affect the scriptc output. Both consume the same `src/routes.chttp.ts`.

## Layout

```
src/
  routes.chttp.ts     # shared routes module (matches the unplugin include glob)
  server.ts           # ELF / node entry: imports `app` from routes.chttp.ts
  client.ts           # consumer of the typed client (typed `api` export)
  .chttp/             # generated by emit-client.mjs
    routes.openapi.ts
    routes.client.ts
scripts/
  emit-client.mjs     # unplugin-driven emit, no bundler
  verify-elf.mjs      # boots the ELF, asserts every verb round-trips
  verify-node.mjs     # boots src/server.ts via node, same assertions
```

## Run

```sh
npm install
npm run build:client   # emit .chttp/* and tsc-build src/client.ts
npm run build:server   # scriptc build src/server.ts -o server
npm run verify:node    # round-trip with a node-served routes module
npm run verify:elf     # round-trip with the native ELF
```

## Why

The two verify scripts share the same client code and the same routes module. `verify:elf` confirms the static binary answers every verb correctly under the typed surface. `verify:node` confirms the unplugin's emit is plain TS and runs without a build step. If the unplugin ever drifts from the openapi/route table, the typed surface either fails to compile or fails an assertion in both scripts.
